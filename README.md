# Listen Labs

Connect Cursor to Listen Labs through its MCP server. Create, edit, launch, and analyze user-interview studies.

## Overview

This plugin connects compatible AI assistants to Listen Labs through its MCP server.

## Installation

### Cursor

1. Open **Customize** in Cursor's sidebar.
2. Find **Listen Labs** in the marketplace.
3. Select **Install** and choose project or user scope.
4. Connect Listen Labs and complete the OAuth sign-in.

Once connected, the plugin also installs the `listen-research` skill, which walks Cursor through creating, editing, launching, and analyzing studies, and confirms with you before spending credits.

Ask Cursor to work with Listen Labs, for example: "Show me my active studies" or "Set up interviews with 25 marketing managers about our pricing."
